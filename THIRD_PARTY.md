# Third-party services and components

- Mojang/Microsoft Minecraft services: version metadata, Microsoft device-code authentication, profile skin and cape operations.
- Modrinth API/CDN: mod search and .jar downloads. Modrinth is an independent third-party service.
- mcsrvstat.us: public Minecraft server status lookup. Server status data may be unavailable or stale.
- CrustCore Rust library: Minecraft Java installation and launch pipeline.
- Tauri 2, Vite, Rust, reqwest, serde and related dependencies: see their respective licenses and package metadata.

Nova Client is not affiliated with or endorsed by Mojang Studios, Microsoft, Modrinth or mcsrvstat.us.
